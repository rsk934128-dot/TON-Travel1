## 📖 পরিচিতি (Overview)

**TON Travel** হলো একটি আধুনিক ও শক্তিশালী **Telegram Mini App & Web Application** যা ব্যবহারকারীদের বিশ্বখ্যাত ৩ মিলিয়নেরও বেশি হোটেল অনুসন্ধান, তুলনা এবং তাত্ক্ষণিক বুকিং করার সুবিধা প্রদান করে। এর মাধ্যমে ব্যবহারকারীরা TON ক্রিপ্টোকারেন্সি, USDT (TON নেটওয়ার্ক) বা আন্তর্জাতিক কার্ডের মাধ্যমে পেমেন্ট সম্পন্ন করতে পারেন এবং প্রতিটি বুকিংয়ে সরাসরি তাদের টেলিগ্রাম ওয়ালেটে **৮% পর্যন্ত TON ক্যাশব্যাক** রিফান্ড পেয়ে থাকেন।

## 🌟 মূল ফিচারসমূহ (Key Features)

### 🏨 ১. হোটেল বুকিং ও সার্চ ইঞ্জিন (Hotel Discovery & Booking)
- **বিশ্বব্যাপী বিস্তৃত ডাটাবেস:** প্যারিস, বালি, দুবাই, টোকিও, নিউ ইয়র্কসহ বিশ্বের যেকোনো শহরের শীর্ষস্থানীয় হোটেল ফিল্টারিং।
- **লাইভ মূল্য ও ক্রিপ্টো কনভার্সন:** প্রতি রাতের রুম ভাড়া স্বয়ংক্রিয়ভাবে USD ও লাইভ TON রেটে হিসাব।
- **ফ্রি ক্যান্সেলেশন ও ব্রেকফাস্ট ফিল্টার:** সম্পূর্ণ বুকিংয়ের সুবিধা ও রিভিউ রেটিং যাচাই।

### 💎 ২. TON ক্যাশব্যাক ইকোসিস্টেম (TON Cashback System)
- **টেলিগ্রাম প্রিমিয়াম বুস্ট:** টেলিগ্রাম প্রিমিয়াম ব্যবহারকারীদের জন্য সরাসরি **৮% বেস ক্যাশব্যাক**।
- **স্ট্যান্ডার্ড ক্যাশব্যাক:** সকল সাধারণ ব্যবহারকারীদের জন্য **৫% ক্যাশব্যাক**।
- **তাৎক্ষণিক ওয়ালেট ক্রেডিট:** বুকিং কনফার্মেশনের সাথে সাথেই ব্যবহারকারীর TON ওয়ালেটে ক্যাশব্যাক যুক্ত হয়।

### 👑 ৩. ফ্রিকোয়েন্ট ট্রাভেলার লয়্যালটি টিয়ার (Loyalty Tier Program)
বিগত ১২ মাসের বুকিং হিস্ট্রি পর্যালোচনা করে স্বয়ংক্রিয় লয়্যালটি স্ট্যাটাস আপগ্রেড:
- 🥉 **Bronze Explorer (১+ বুকিং):** বেস ক্যাশব্যাক + **০.৫% বোনাস**
- 🥈 **Silver Voyager (৩+ বুকিং):** বেস ক্যাশব্যাক + **১.০% বোনাস**
- 🥇 **Gold Jetsetter (৫+ বুকিং):** বেস ক্যাশব্যাক + **২.০% বোনাস** + ফ্রি এয়ারপোর্ট লাউঞ্জ
- 💎 **Diamond VIP (১০+ বুকিং):** বেস ক্যাশব্যাক + **৩.৫% বোনাস** + সর্বোচ্চ প্রায় ১১.৫% ক্যাশব্যাক

### 🔥 ৪. ডেইলি রিওয়ার্ডস ও স্ট্রিক ক্যালেন্ডার (Daily Rewards & Streak System)
- প্রতিদিন লগইন করে বিনামূল্যে TON ক্যাশব্যাক রিওয়ার্ড ক্লেম করার সুযোগ।
- ১ থেকে ৭ দিনের ধারাবাহিক স্ট্রিক পূর্ণ করে বিশেষ জ্যাকপট বোনাস।
- রিয়েল-টাইম ২৪ ঘণ্টার কাউন্টডাউন কুলডাউন টাইমার।
- টেলিগ্রাম প্রিমিয়াম সদস্যদের জন্য **+২৫% অতিরিক্ত বুস্ট**।

### 🎨 ৫. পারসোনালাইজড থিম কাস্টমাইজেশন (Accent Color Theming)
- 🔵 **Telegram Blue** (`#0088cc`)
- 🟣 **TON Crystal Purple** (`#7842e6`)
- 🟢 **Emerald Oasis Green** (`#059669`)
- তাৎক্ষণিক থিম পরিবর্তন এবং ব্রাউজার লোকাল স্টোরেজে স্বয়ংক্রিয় সেভ।

### 📱 ৬. ডিজিটাল চেক-ইন ও গুগল ড্রাইভ ব্যাকআপ (Front Desk Pass & Cloud Sync)
- **QR কোড চেক-ইন পাস:** হোটেল ফ্রন্ট ডেস্কে দ্রুত চেক-ইন করার জন্য হাই-কনট্রাস্ট QR কোড ও ডিজিটাল ভাউচার।
- **Google Drive রসিদ সিঙ্ক:** বুকিং কনফার্মেশনের সাথে সাথে অফিসিয়াল পিডিএফ/ইনভয়েস স্বয়ংক্রিয়ভাবে ব্যবহারকারীর গুগল ড্রাইভে সংরক্ষণ।

### 📲 ৭. PWA এবং মোবাইল হোম স্ক্রিন সাপোর্ট (PWA & Mobile Ready)
- অ্যান্ড্রয়েড, আইওএস (iPhone/iPad) ও ডেস্কটপে ইনস্টলযোগ্য।
- হোম স্ক্রিন লঞ্চারের জন্য ৩ডি ক্রিস্টাল লোগো ও স্প্ল্যাশ স্ক্রিন কনফিগারেশন।
- ব্রাউজার ফেভিকন এবং সোশ্যাল মিডিয়া প্রিভিউ (Open Graph) সংযুক্ত।

## 🚀 ইনস্টলেশন ও রান করার নিয়ম (Getting Started)

### পূর্বশর্ত (Prerequisites)
- [Node.js](https://nodejs.org/) (ভার্সন 18 বা তার বেশি)
- [npm](https://www.npmjs.com/) অথবা [yarn](https://yarnpkg.com/)

### ১. ডিপোজিটরি ক্লোন করুন
```bash
git clone <repository-url>
cd ton-travel-app
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
সার্ভারটি `http://localhost:3000` পোর্টে রান হবে।

### ৪. প্রোডাকশন বিল্ড তৈরি করুন
```bash
npm run build
```
